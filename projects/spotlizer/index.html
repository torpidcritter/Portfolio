Spotlizer

Predicts whether a song will be popular from its Spotify audio features, with a Streamlit app for exploring predictions.

My role
Built the full pipeline: data loading, preprocessing, EDA, model training, evaluation and the app.
Status
—
Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit
Links
Source code (opens in a new tab)

Problem

Can loudness, energy, danceability and the rest of a track's audio profile say anything about whether it will be popular?

Capabilities

  • Spotify audio feature analysis and EDA
  • Feature engineering and scaling
  • Random Forest classification
  • Evaluation by accuracy, precision, recall, F1 and confusion matrix
  • Batch prediction and a Streamlit interface
